This project contains modifications to WRF code, sourced from 2 previous projects ported over to WRF v4.6.0. The 2 projects: WRFlux and wrf_lrf_les are linked below.

https://github.com/Nathan1291/wrf_lrf_les

https://github.com/matzegoebel/WRFlux/tree/master

The code has been modified so that it can be simply compiled on GADI by running:

```
./run_compile --clean --compile_case em_quarter_ss
```
